# Магазин «Сад и огород» — админка

Интерфейс админки на русском. Пользователи админки — менеджеры магазина, не программисты.

## Ошибки
Любая ошибка, которую видит пользователь, содержит: стабильный код (например, APP_PRODUCT_SAVE_FAILED),
понятный текст на русском без технических деталей и следующий шаг. Технические детали — только в логах.
Серверные ошибки создаются через `AppError` из `server/errors.js`.

## Фоновые задачи
Всё, что дольше 5 секунд, выполняется через очередь `server/jobs/queue.js`; результат пользователь
получает уведомлением в админке (`server/notifications.js`).
